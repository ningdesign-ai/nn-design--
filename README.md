# 宁宁的作品集网站

这是一个简单的静态个人作品集页面，适合视觉设计师展示视频和图文作品。

## 特点

- 纯静态网页，可以在任意浏览器中打开
- 简洁白色风格，参考 Behance 的展示方式
- 分为“视频作品”和“图文作品”两个部分
- 半公开访问：只有带有访问码的链接可以直接进入

## 如何打开

1. 在文件管理器中双击 `index.html`
2. 或者在浏览器中打开 `index.html`
3. 打开后如果看不到内容，请使用分享链接访问。

> 访问者通过分享链接进入作品展示页，无法上传内容。

## 直接分享给别人

这个项目已经是静态网页版本，可以直接部署到静态网站托管服务。

- 发给别人的链接是一个临时分享链接，格式类似：

  `https://你的域名或平台地址/index.html?share=1234&exp=时间戳`

- 你自己的编辑入口是：

  `https://你的域名或平台地址/lock.html`

- 作者登录后会跳转到 `index.html?access=portfolio-edit`。

- 作者主密钥请联系仓库拥有者获取，不要直接公开在文档中。

## 推荐的简单托管方式

### 1. GitHub Pages

1. 在 GitHub 上创建一个新的仓库。
2. 将项目文件上传到仓库。
3. 在仓库设置里启用 GitHub Pages，选择 `main` 分支的 `root` 目录。
4. 生成后你会得到一个网址，像 `https://你的用户名.github.io/你的仓库名/`。
5. 直接分享 `.../index.html?share=1234&exp=时间戳`。

### 2. Netlify

1. 注册 Netlify 账号。
2. 新建一个站点，选择上传整个项目文件夹。
3. 发布后会生成一个网站地址。
4. 分享时同样使用 `.../index.html?share=1234&exp=时间戳`。

> 这样你就可以把网页地址直接发给别人，别人打开后会直接看到你的作品展示页。
> 如果仍然无法进入页面，可直接点击页面上的“直接进入作品集”按钮。

## 如何分享

复制你的页面地址，并使用带有分享参数的链接，例如：

`file:///Users/ningning/Downloads/宁宁作品集/index.html?share=1234&exp=时间戳`

> 这样别人打开时就能直接进入作品集页面。没有有效分享参数的链接会看到访问提示页。

## 如何上传作品

1. 打开 `lock.html`。
2. 访问者请使用带有分享参数的链接进入，例如：`index.html?share=1234&exp=时间戳`。
3. 如果你是作者，需要先打开 `lock.html`，输入 `portfolio-edit` 或长期有效的主密钥，然后系统会跳转到作品集首页。
3. 在“上传作品”区域选择视频或图文文件。
4. 填写图文作品的标题和描述。
5. 点击“上传视频”或“上传图文”，上传后的作品会显示在页面下方。

## 分享链接生成器

在作者模式下，你可以点击“生成分享链接”，系统会自动生成一个带有4位密钥的私密分享链接，链接有效期为3天。

- 你可以把生成的“分享链接”直接发给别人
- 别人打开后就能查看作品展示页
- 这个链接包含一个临时密匙和过期时间，过期后失效

## 如何修改作品

### 视频作品

你可以直接使用上传功能，或者在 `index.html` 的“视频作品”区域把占位内容替换成你的项目介绍。

### 图文作品

你可以直接使用上传功能，或者在 `index.html` 的“图文作品”区域把占位图换成你的作品图片，并修改标题和描述。

## 说明

这个网站是静态页面，不包含自动上传功能。如果你需要“上传作品”功能，需要额外的服务器或在线服务支持。现在你可以先用这个页面展示你的作品，再逐步升级。
